# Phase 09 — Hardening and Release

## Objective
Bring Fetch to release acceptance.

## Required work
- full architecture audit;
- process cleanup/crash recovery audit;
- migration audit;
- Windows/Linux/macOS packaging;
- CI release matrix;
- checksums;
- license notices;
- FFmpeg distribution/license review;
- responsive UI final pass;
- performance checks;
- external smoke tests;
- release docs.

## Acceptance criteria
- [ ] all mandatory tests pass.
- [ ] no production mocks/stubs remain.
- [ ] no forbidden architecture exists.
- [ ] release runtime requires no Node.js.
- [ ] runtime prepares on a clean target machine.
- [ ] target packages start successfully.
- [ ] licenses/notices included.
- [ ] README is accurate.
- [ ] ISSUES.md has no release-blocking open defects.
