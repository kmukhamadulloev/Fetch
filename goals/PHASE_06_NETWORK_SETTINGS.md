# Phase 06 — LAN and Settings

## Objective
Finish configurable local server access.

## Required work
- bind address;
- port;
- allowed CIDR list;
- CIDR middleware;
- local/LAN URL discovery;
- settings UI;
- no-auth warning;
- safe rebind/restart behavior.

## Acceptance criteria
- [ ] localhost works.
- [ ] allowed LAN clients work.
- [ ] denied remote addresses rejected.
- [ ] invalid CIDRs cannot be saved.
- [ ] invalid bind/port settings are typed errors.
- [ ] no auth/pairing introduced.
- [ ] no automatic router exposure.
- [ ] tests pass.
